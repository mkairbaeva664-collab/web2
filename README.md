### Task 2 — Page Layout with Grid Areas

I created a page layout consisting of a header, sidebar, main content, and footer.

CSS Grid was used to divide the page into rows and columns and to assign different sections to named grid areas.

The layout has:
- Header across the top;
- Sidebar on the left;
- Main content on the right;
